## Специфіка workstation
- Ціль — Raspberry Pi 4 (два дисплеї) оператора. Код пишеться на цьому ПК, запускається на RPi 4 через SSH/`rsync` або `git pull` — будь-який запуск на пристрої лише за командою користувача.
- Задачі, що вимагають перевірки на реальному RPi 4 (дисплеї, продуктивність відео), мають `hil_required: true`: завершення — лише після письмового PASS від користувача.
- Жодних секретів у git; конфіг підключення до server — через `.env`.
