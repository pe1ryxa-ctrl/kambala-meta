# Чипи аналогового захоплення (CVBS/PAL) — що нам підходить

Коротка пам'ятка для власного стрімера / вузла. Докладно — `docs/research/grabbers-raw-field.md` (дослідження хмари 2026-09-29), заміри — `Global_Context.md` (KSIM-009, експеримент зі Streamer 2026-09-17).
Критерій: сирий кадр (YUYV/UYVY) без внутрішньої буферизації чипа, драйвер у mainline Linux (є в Raspberry Pi OS). Напівкадр (720x288@50) з коробки не дає жоден — лише патчем драйвера.

## Не брати

- **MS2106** `534d:0021` — продається під назвами «UTV007» і «DC60»; UVC, імовірно буферизує як MS2107.
- **«Chipset 008» / «DC60-008»** — заміна UTV007, драйвер невідомий.
- **MS2109 / `345f:*`** — HDMI-захоплювачі того ж сімейства, що MS2107.
- **«USB2.0 PC CAMERA»**, лише MJPEG 640x480 — аналоговий захоплювач усередині FlyByIP Streamer (прочитано з API 2026-09-29); сирого формату немає.
- **Somagic SMI2021** `1c88:0007`/`003c` — поза mainline, потрібна прошивка.
- **TW6869/TW686x (PCIe)** — у CM4-DUAL-ETH-BOX-A немає вільної лінії PCIe, модуль вимкнено в RPi defconfig.

## Як купувати

Назва в оголошенні нічого не гарантує («EasyCAP», «DC60», «UTV007» ставлять на будь-який чип). Просити фото плати або вивід `lsusb`; брати з можливістю повернення; після отримання — `lsusb` і `v4l2-ctl --list-formats-ext` до заміру.
Наявність на 2026-09-29: Pinnacle Dazzle DVC100 (EM2820) — OLX, Рівне, 1 350 грн, вживаний, повний комплект (https://www.olx.ua/d/uk/obyavlenie/otsifrovka-videokasset-plata-videozahvata-pinnacle-dazzle-dvc100-dlya-otsifrovki-vhs-ID11dFDZ.html); EM2860 / Grabby / USB-Live2 в Україні не знайдено (USB-Live2 — лише перепродаж з Allegro без ціни); підтвердженого UTV007 чи STK1160 в Україні в наявності не знайдено (prom.ua — лістинги видалено або «недоступний», uawest — «немає в наявності»); AliExpress чип у лістингах не вказує.
