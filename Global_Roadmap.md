# Kambala — Global Roadmap

Стратегічна дорожня карта екосистеми. Веде Claude (L2). Етап закривається лише після аудиту Архітектора та підтвердження Gans.

## Поточна пріоритетна послідовність

### 🟡 Фаза 0: Розгортання середовища та SSOT [АКТИВНО]
- **Мета:** репозиторії `server`, `workstation`, `node-sim` створені; у кожному — Holy Trinity; `Global_Context.md` звірено з `docs/technical_specification.md`; крос-проєктні контракти зафіксовано.
- **Підпроєкти:** усі.
- **Критерій завершення:** перші задачі `KSRV-001`, `KSIM-001`, `KWS-001` (створення Holy Trinity) — `done`.

### ⏳ Фаза 1: Ground Control — відео та телеметрія в браузері
- **Мета:** підключити FlyByIP Streamer (спершу — симулятор на RPi 5) до server і показати відео та базову телеметрію у веб-інтерфейсі для адміністратора/тестувальника.
- **Підпроєкти:** node-sim → server → workstation.
- **Критерій завершення:** HIL PASS від Gans на реальному Streamer через MikroTik/WireGuard.

### ⏳ Фаза 2: Пілотський контур
- **Мета:** плагін QGroundControl, mTLS, exclusive control lock, пускові бокси (Pico 2 / CAN).
